# BE-20 (P2) — Статус «прочитано собеседником»: lastReadSeq и/или событие chat.read

Статус «прочитано собеседником»: `lastReadSeq` в составе участников (`ChatMemberDto`) и/или WS-событие о чтении (в т. ч. для других вкладок читающего — расхождение `unreadCount`). Нужно решение пользователя по форме (событие `chat.read`, кому рассылать). Зависит от: BE-D23, решения пользователя.

# BE-46 (P2) — NUL и управляющие символы во входном тексте → ожидаемый 500, решить код ответа

NUL и другие управляющие символы во входном тексте (имена `firstName`/`lastName`, названия чатов, сообщения, логин/пароль) → Postgres не принимает `0x00` в `text`, ожидается `500`. Сначала проверить воспроизведением, что это действительно `500`; затем решить код ответа (вероятно, `400 validation_failed` + `details` `invalid_format` там, где есть `details`) и набор запрещённых символов — вопрос пользователю. Найдено ревью BE-38.

# BE-47 (P3) — Лимит на смену пароля POST /api/me/password (два argon2 на запрос)

Нет IP-лимита и лимита на успешные смены пароля у `POST /api/me/password`: каждый запрос стоит два argon2 (проверка + хэш), успех сбрасывает счётчик по логину, поэтому владелец сессии (или украденная сессия) может гонять сервер без `429`. Рассмотреть `AuthRateLimitGuard` или лимит на пользователя; связано с BE-45 (защита главного потока от argon2). Найдено ревью BE-39.

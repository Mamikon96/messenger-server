# BE-22 (P1, клиент `messenger-client-react`) — Клиент: вход/регистрация по логину и паролю (messenger-client-react)

Перейти на вход и регистрацию по логину/паролю (спека `docs/auth-password-spec.md`, копия у клиента; решение клиента FE-D38): форма входа/регистрации, настройки имени, смена пароля, «выйти на всех устройствах»; выход из системы только при `401 unauthorized` (`401 auth_failed` — ошибка формы). Прежний план перехода на passkey отменён (SH-D18). Зависит от: BE-29.

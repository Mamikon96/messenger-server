# BE-60 (P3) — Харнес: разобрать рост «System tools» 6,0 → 7,7 тыс. после выключения плагинов (BE-58)

После BE-58 замер `claude -p --model opus "/context"` показал рост категории «System tools» с 6,0 до 7,7 тыс. токенов при той же модели (SH-D22). Выяснить причину (вероятно, порог отложенной загрузки инструментов при малом числе MCP-инструментов) и, если управляемо, вернуть инструменты в отложенные.

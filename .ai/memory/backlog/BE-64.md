# BE-64 (P3) — markRead после удаления чата или участника отдаёт 400 вместо 404

`MessagesService.markRead` (`src/messages/messages.service.ts`, около :134-148) проверяет членство без блокировки чата. Если между проверкой и `UPDATE` чат удалён (BE-52) или участник удалён (`removeMember`), `UPDATE` затрагивает 0 строк и клиент получает `400 "seq is beyond the last message"` вместо `404`. Исправить: различать «0 строк из-за удаления» и «seq за пределами», либо брать блокировку. Сначала e2e на гонку. Найдено аналитиком при разборе BE-52.

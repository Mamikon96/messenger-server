# BE-52

2026-10-18 — Удаление группы владельцем: `DELETE /api/chats/:id` (CSRF) → `204`. Только `group` и только owner; порядок ошибок: `404` (нет чата или не участник) → `400` (direct) → `403` (не owner); повтор → `404`. Участники и сообщения удаляются каскадом (миграции нет), история не архивируется. `chat.removed {chatId}` получают все участники на момент удаления, включая owner; в пустой группе (BE-51) получатель только owner. Решение пользователя: жёсткое удаление, получатели включая owner, `markRead` вынесен в BE-64.

Тип: контракт API и WS-событие. `system-analyst` до тестов выполнен. Приёмка: `accept.sh` = 0 (unit 502, e2e 346). Ревью: nestjs-reviewer APPROVE (MINOR/NIT по тесту гонки и direct-кейсу приняты к сведению).

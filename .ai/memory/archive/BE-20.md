# BE-20

2026-10-19 — Статус «прочитано собеседником». `ChatMemberDto` содержит `lastReadSeq` (`GET /chats/:id`, `chat.created`, `chat.updated`); в `GET /chats` у direct-чата есть `peer.lastReadSeq`, у group поля нет. `POST /chats/:id/read {seq}` со сдвигом отдаёт 204 и публикует `chat.read {chatId, userId, lastReadSeq}` всем текущим участникам, включая читающего; без сдвига — 204 без события; `seq` больше `last_seq` — 400; не участник или чат удалён — 404. `markRead` выполняется в транзакции с порядком блокировок «чат → участник», как в `send`. Удалённый участник `chat.read` не получает. Обновлены `docs/contract.md`, `docs/client-integration.md` (§4, §6, §8), `product-agreements.md`.

# AI-контекст проекта (backend)
Принцип: агент читает **только** файлы, нужные для текущей задачи. Маршрутизатор «задача → файлы» один — в `CLAUDE.md` (грузится всегда); здесь только раскладка.

```
.ai/
  rules/     # правила работы (как делать): читать по маршрутизатору CLAUDE.md
  memory/    # состояние проекта (что есть): читать по необходимости, описание — memory/README.md
.claude/
  agents/    # проектные агенты; перекрывают одноимённые глобальные (SH-D15)
  settings.json  # права и hooks (скрипты — scripts/hooks/)
```

Файлы с пометкой «Читать:» в первой строке содержат условие применимости — если оно не про вашу задачу, файл не открывать.

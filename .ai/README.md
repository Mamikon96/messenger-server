# AI-контекст проекта (backend)
Принцип: агент читает **только** файлы, нужные для текущей задачи. `CLAUDE.md` (грузится всегда) — краткий индекс; детали — здесь.

```
.ai/
  rules/     # правила работы (как делать): читать по теме
  memory/    # состояние проекта (что есть): читать по необходимости
```

## Маршрутизатор: задача → файлы
| Задача | Читать |
|---|---|
| Любая задача разработки (старт) | `rules/memory-protocol.md`, `memory/tasks.md` |
| Новый/изменённый модуль, контроллер, сервис, DTO, миграция | `rules/code-style.md` (+ `memory/architecture.md`, если трогаешь структуру или схему БД) |
| Написать/починить тесты, реализовать новое поведение | `rules/testing.md` |
| Баг, регрессия, «что сейчас сломано» | `memory/state.md` |
| Исследование/планирование задачи, проектирование API/схемы/событий | `rules/research-planning.md` (подключить `system-analyst`) |
| Нужна новая библиотека/паттерн | `rules/tech-approval.md`, затем заголовки `memory/**/decisions.md` |
| Контракт API/событий, реалтайм, серверное хранение | `memory/product-agreements.md` |
| Закрыть задачу (приёмка, ревью) | `rules/acceptance.md` |
| Финальный отчёт | `rules/report-format.md` |
| Сомнение, неоднозначность, не хватает данных (**любая** задача) | `rules/ask-user.md` (**обязательно**) |
| Правка самой структуры памяти | `memory/README.md`, `scripts/check-memory.sh` |

Файлы с пометкой «Читать:» в первой строке содержат условие применимости — если оно не про вашу задачу, файл не открывать.

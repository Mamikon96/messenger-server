# Приёмка задач
Читать: когда задача реализована и нужно решить, можно ли её закрыть.

В архив («Сделано»: файл `.ai/memory/archive/<слаг>.md` и строка сверху индекса `.ai/memory/tasks-archive.md`) — только при **обоих** условиях:
1. `bash scripts/accept.sh` → код 0 (проверка памяти и сверка кода с контрактом `scripts/check-memory.sh` + lint + build + unit + e2e).
2. Ревьюер `nestjs-reviewer` вынес **APPROVE** по текущему коду (ревью — после зелёной приёмки).

Порядок: реализация → `bash scripts/accept.sh` → ревью → при `REJECT`/`APPROVE WITH FIXES` исправить все BLOCKER и MAJOR, повторить приёмку и **повторное** ревью → запись в «Сделано» с пометкой `ревью: nestjs-reviewer APPROVE`.
**Повторное ревью** — новый `nestjs-reviewer` (не `SendMessage` прежнему): в промпт — список прошлых замечаний (`[уровень] путь:строка — проблема`) и диапазон фикса (`git diff <sha до фикса>` или список коммитов). Ревьюер проверяет закрытие каждого замечания и только дифф фикса, а не всю ветку заново (SH-D19).
Субагенты других агентов не запускают: ревью запускает основная сессия. Ревью не пройдено — задача остаётся «В работе» с пунктом «Осталось: ревью».
Изменения только конфигов/процесса/документации — ревью не требуется (отметить это в записи).
После закрытия — push ветки и PR по `git-flow.md`.

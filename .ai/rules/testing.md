# Тесты
Читать: при написании/правке тестов и перед реализацией любой задачи с новым поведением.

- Порядок: **сначала тесты, потом реализация** (тесты должны падать до кода).
- Новое поведение = unit и/или интеграционный/e2e-тест в рамках той же задачи.
- Стек: Vitest + supertest + `@nestjs/testing` (BE-D04). Unit — `src/**/*.spec.ts` рядом с кодом (`npm test`); e2e — `test/*.e2e-spec.ts` (`npm run test:e2e`).
- Целиком: `bash scripts/accept.sh` (см. `acceptance.md`).
